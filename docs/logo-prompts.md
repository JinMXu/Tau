## 1. 方向 A：半圆补全 ⭕（推荐，最贴品牌概念）

**视觉**：一个开放半圆弧 + 同一条弧线继续延伸闭合为完整圆环，直观演绎 τ = 2π。

**Midjourney 英文提示词：**

```
Minimalist geometric logo for a desktop AI coding app called "Tau" (Greek letter τ).
Core concept: τ = 2π — pi draws only a half circle, tau completes it into a full circle.
Design: a single open half-circle arc on the left, with the same arc extending to close
into a complete circular ring, as if the second half completes the first.
Pure 2D vector style, flat design, thin uniform stroke, warm neutral palette
(warm off-white background, ink-black main color, subtle terracotta accent),
generous negative space, no text, no gradients, no 3D, no photorealism,
single centered symbol, crisp edges, suitable as an app icon.
--ar 1:1 --v 6 --style raw
```

**即梦 / 豆包（中文）：**

```
极简几何 Logo，为名为「Tau（τ）」的 AI 编程桌面客户端设计。
核心概念：τ = 2π —— π 只画了半个圆，Tau 把它补成完整的圆。
画面：左侧一个开放的半圆弧，弧线顺势延伸、闭合为完整的圆环，
象征"补全"。纯扁平矢量风，均匀细描边，暖中性配色
（暖米白背景、墨黑主色、点缀陶土色），大量留白，
无文字，无渐变，无 3D，无光效，单一居中图形，边缘锐利，正方形构图。
```

## 5. SVG 矢量实现提示词（推荐最终用这个落地）

AI 绘图生成的位图 → 用作概念稿；**最终图标建议让代码模型直接生成 SVG**（矢量，任意尺寸锐利，可直接作为 Tauri 图标源）。以下是给 Claude/GPT 等编程模型的 SVG 提示词：

**方向 A（半圆补全）SVG：**

```
生成一个极简 Logo 的 SVG，用于 "Tau" —— 一个 AI 编程代理的极简桌面客户端。

设计要求：
1. 画面中央是一个由"半圆弧 + 延伸补全的完整圆环"构成的图形：
   一条弧线从左侧 180° 开放半圆开始，继续延伸约 180° 闭合为整圆，
   象征 τ = 2π（π 的半圆被 tau 补全）。
2. 纯扁平矢量，单一圆环线宽均匀（stroke-width 约为画布 3%），
   stroke-linecap="round"，无填充或极简填充。
3. 配色：暖米白背景（#F5F1EA），主图形墨黑（#1F1D1A），
   可在补全段用陶土色（#C2674A）作点缀区分。
4. 画布 1024×1024，图形居中，四周留白 15%。
5. 输出完整可用的 <svg> 代码，不要省略号。
```

**方向 B（τ 字标）SVG：**

```
生成一个极简字标 SVG，用于 "Tau"（希腊字母 τ）。

设计要求：
1. 主体是几何化的希腊字母 τ：一条竖直主干（居中），顶部一条水平弧线，
   弧线恰为半圆轮廓（半径 = 主干宽度的约 3 倍），弧的两端略超出主干。
2. 视觉上要像"半个圆扣在竖线上"，暗示 τ = 2π。
3. 均匀细线宽（stroke-width 约为画布 2.5%），stroke-linecap="round"，
   无填充。
4. 配色：暖米白背景（#F5F1EA），墨黑描边（#1F1D1A），
   弧顶右侧加一个陶土色（#C2674A）小圆点作点缀。
5. 画布 1024×1024，字形居中，四周留白 20%。
6. 输出完整可用的 <svg> 代码，不要省略号。
```

## 6. 落地到 Tauri（位图方案）

选定 SVG/PNG 后，用 Tauri 官方命令一键生成全部平台图标尺寸：

```bash
# 前提：有一张 1024x1024 的源图 logo.png（SVG 可先转 PNG）
npx tauri icon ./logo.png
```

该命令自动覆盖 `src-tauri/icons/` 下的 icon.ico / icon.icns / 各尺寸 PNG，Windows 托盘、macOS Dock、Linux 桌面图标一次到位。侧边栏/关于页内的 logo 直接用 SVG 组件或 `<img>` 引用。

## 7. 评审清单

出图后逐项打分（每项 0–2 分）：

- [ ] 概念表达：能看出"半个圆被补全"或 τ 的意象
- [ ] 极简度：缩小到 16px 后依然可辨识（图形是否够简单）
- [ ] 扁平度：无渐变/3D/光效
- [ ] 配色：符合暖中性 + 墨黑 + 陶土点缀的调性
- [ ] 留白：图形四周留白充足，居中
- [ ] 剪影识别：只看纯黑剪影也能认出
