# Pi Desktop UI 重设计 — 设计文档

日期：2026-08-11
状态：已获用户批准

## 背景与目标

Pi Desktop（Tauri 2 + React 19 + Vite）当前 UI 存在四类痛点（用户确认）：图标简陋且风格不统一、会话输出可读性差、整体视觉过时、信息层级不清。

本次重设计的目标：

1. 重建设计 Token 体系（色阶 / 字阶 / 间距 / 圆角 / 阴影 / 动效）。
2. 全量重绘图标（约 30 个），统一为 1.5px 细线风格。
3. 重点优化会话输出体验：文档流结构 + 状态化工具行 + 代码块头部 + 思考块与流式状态细节。
4. 全部界面（侧边栏、Composer、设置页、搜索浮层、对话框、Toast）统一迁移到新视觉体系。

## 已确认的方向决策

- **视觉方向**：暖中性精修（延续 Ousia 气质），保留 6 套 accent（Mist/Paper/Sand/Gray/Forest/Ocean）与亮/暗双主题。不做冷灰编辑器风，不做深色品牌风。
- **覆盖范围**：全部界面一起升级，会话输出为重点。
- **图标风格**：24×24 网格、1.5px 描边、圆角端点、`currentColor`。
- **会话输出结构**：文档流 + 状态化工具行（非卡片化分区）。
- **实施路径**：设计 Token 先行，分两阶段（阶段 1 可独立验收）。

## 设计 · 第 1 节：设计 Token 体系

在现有 `:root`（accent / 色阶 / 密度变量）基础上补齐，全部新样式只引用 token：

- **色阶**：新增语义层
  - `--text-1 / --text-2 / --text-3`（正文 / 次级 / 弱化）
  - `--surface-0 / --surface-1 / --surface-2`（面板 / 卡片 / 悬浮）
  - `--border-1 / --border-2`
  - `--status-ok / --status-warn / --status-err / --status-run`（工具行状态点）
  - 每套 accent、亮暗主题均需定义上述语义变量。
- **字阶**：`--fs-xs(11) / --fs-sm(12.5) / --fs-md(14) / --fs-lg(16) / --fs-xl(20)`；正文行高 1.6；代码使用 ui-monospace 字体栈；现有"字号"设置项继续作用于根字号，各字阶以 em/rem 相对派生，设置项交互不变。
- **间距**：4px 基栅 `--sp-1..--sp-6`（4 / 8 / 12 / 16 / 24 / 32）。
- **圆角**：`--r-sm(6) / --r-md(9) / --r-lg(14)`；工具行与代码块用 md，气泡与卡片用 lg。
- **阴影**：两级柔和投影（卡片级、浮层级）；暗色主题下以边框替代投影。
- **动效**：统一 `--ease` 曲线与 150ms 时长，仅用于 hover / 展开 / 状态变化；遵守 `prefers-reduced-motion`。

## 设计 · 第 2 节：图标系统

- **规格**：24×24 viewBox、1.5px 描边、`stroke-linecap/linejoin: round`、`currentColor`；关键节点吸附半像素网格，保证 12 / 14 / 16px 三档清晰。
- **结构**：保持 `src/icons.tsx` 现有导出名与 `size` prop 不变，仅替换 path，调用方零改动。
- **重绘清单**：现有约 30 个图标全量过一遍，其中重点重设计：
  - 工具类图标成体系：终端（`>_`）、读/列目录、写/编辑、搜索、补丁/闪电、通用火花——统一圆角半径与视觉大小；
  - `SparkleIcon`：由"米字"改为四角星形；
  - `MoreIcon`、`StopIcon` 等实心款改为与细线风格一致的表达；
  - 新增：代码块 copy、语言标签、思考块、耗时等会话输出新细节所需图标。
- **验收**：12 / 14 / 16px 三档目视检查；亮暗主题对比度达标。

## 设计 · 第 3 节：会话输出（重点）

涉及 `src/components/MessageList.tsx`、`src/components/Markdown.tsx` 及 `src/App.css` 对应区块。

- **消息结构**：
  - 会话列居中，最大宽度约 720px；
  - 助手消息：无气泡、全宽文档流，顶部小字 `PI` + 模型徽标；
  - 用户消息：右侧暖沙色气泡，hover 显示时间；
  - 回合之间以留白分隔，不用分割线；
  - `history` 徽标保留并弱化。
- **工具调用行**（默认折叠为单行）：
  - 状态点：运行中（琥珀色脉冲）/ 成功（绿）/ 失败（红）；
  - 1.5px 分类图标 + 工具名 + 关键参数摘要（bash→命令、read/edit→文件路径、grep→pattern，超长截断）；
  - 右侧耗时 + chevron；
  - 点击展开：参数 + 结果输出（等宽字体、max-height 内部滚动）；
  - 写文件工具保留"打开文件"快捷操作；
  - 数据约束：状态与耗时以 Pi RPC 实际可提供的数据为准，拿不到则不显示，不做假数据；参数摘要 JSON 解析失败时回退为原始截断文本（与现有行为一致）。
- **思考块**：单行折叠态 `Thought for Ns ▸`（弱化色），展开后为弱化色正文；流式思考中显示脉冲点。
- **代码块**：头部卡片——左侧语言标签、右侧 copy 按钮（点击后变 ✓）；深色暖底；rehype-highlight 配色按暖色调校；横向滚动不换行；不做行号。
- **Markdown 细节**：标题 / 列表 / 引用 / 表格 / 行内 code 按新字阶与间距重排；链接下划线 hover；表格斑马纹 + 圆角边框。
- **流式状态**：文本末尾软闪烁块光标（替代细竖线）；回合等待指示器接入新 token；`prefers-reduced-motion` 时关闭闪烁与脉冲。
- **错误**：消息级错误使用 `--status-err` 弱化横幅样式，不用裸红字。

## 设计 · 第 4 节：其余界面迁移

仅迁移视觉（token + 图标），不改变功能、布局结构与交互流程。

- **侧边栏**：项目分组标题、会话行、底部搜索/设置入口换新 token；选中态由色块改为左侧 2px accent 指示条 + 浅底；拖拽排序不变。
- **Composer**：悬浮胶囊保留；圆角 / 边框 / 聚焦态接入新 token；工具栏按钮统一 1.5px 图标 + hover 浅底；模型 / 思考级别菜单、分支按钮、附件 chips 样式对齐。
- **设置页 / 搜索浮层 / 扩展对话框 / Toast**：token + 图标迁移。

## 阶段划分

- **阶段 1**：token 体系 + 图标全量重绘 + 会话输出（MessageList / Markdown / Composer）。
- **阶段 2**：侧边栏、设置页、搜索浮层、对话框、Toast 迁移。

每阶段独立验收，中间状态不出现风格割裂（阶段 1 完成后其余界面仍用旧样式但引用兼容变量）。

## 错误处理与边界

- 纯样式与组件结构改动，不改任何 IPC / 状态逻辑，不动 Rust 后端。
- 工具参数摘要解析容错（JSON.parse 失败回退原始截断文本）。

## 验收标准

- `npm run build`（tsc + vite）通过。
- `cargo test --manifest-path src-tauri/Cargo.toml --lib` 不受影响。
- `npm run tauri dev` 人工走查：亮 / 暗 × 至少 2 套 accent、三档消息密度、中英双语下的会话输出与主界面。
- 图标在 12 / 14 / 16px 三档清晰。

## 不做（YAGNI）

- 不改信息架构与交互流程。
- 不加代码行号、消息反应等新功能。
- 不动 Rust 后端与 Pi RPC 协议。
